# Market Research Agent — Design Spec
**Date:** 2026-04-15
**Status:** Design approved, ready for implementation planning

---

## Context

This is a new project (empty directory at `D:\AI\Business\Project 3`) to build an autonomous AI agent that produces structured market research reports. The user wants a browser-based interface where they can submit a research topic and receive a well-structured, multi-section markdown report generated by a multi-step research pipeline powered by Claude.

**Problem it solves:** Manual market research is time-consuming. This agent automates the process of planning research queries, searching the web, synthesizing findings, and writing a structured report — all triggered by a single topic input.

---

## Architecture

Three-layer system:

```
React Frontend  ←→  FastAPI Backend  ←→  Agent Pipeline (Python)
                          ↓
                       SQLite DB
                          ↓
                    Tavily Search API
                          ↓
                    Claude (Anthropic API)
```

**Frontend (React + TypeScript):** SPA with a research form, real-time progress tracker (4 pipeline stages), markdown report viewer, download button, and list of past reports.

**Backend (FastAPI):** REST API + SSE. Accepts research requests, runs the pipeline as a background task, exposes job status and results. Persists jobs/reports to SQLite.

**Agent pipeline (Python):** Four pure functions (plan → search → synthesize → write), orchestrated by a pipeline runner. Each stage updates job status in the DB.

---

## Agent Pipeline Stages

### Stage 1 — Plan
- Input: research topic (string)
- Claude generates 5–8 targeted search queries covering: market size, key players, trends, opportunities, challenges, and regulatory landscape
- Output: `list[str]` of search queries

### Stage 2 — Search
- Input: list of search queries
- All queries run in parallel via Tavily Search API
- Each query returns 3–5 results: URL, title, content snippet
- Output: `list[SearchResult]` (~25–40 total snippets)

### Stage 3 — Synthesize
- Input: raw search results
- Claude synthesizes into structured findings: key themes, data points, source notes, coverage gaps
- Output: structured synthesis text (markdown)

### Stage 4 — Write
- Input: synthesis
- Claude writes the final report in structured markdown
- Report sections:
  1. Executive Summary
  2. Market Overview (size, growth, geography)
  3. Key Players & Competitive Landscape
  4. Trends & Opportunities
  5. Challenges & Risks
  6. Conclusions & Recommendations
- Output: full markdown report string

## Data Model

### `ResearchJob` (SQLite table)
| Field | Type | Notes |
|-------|------|-------|
| id | UUID (str) | Primary key |
| topic | str | User-submitted research topic |
| status | enum | `pending`, `running`, `done`, `error` |
| current_stage | str | e.g., `"plan"`, `"search"`, `"synthesize"`, `"write"` |
| report_markdown | text | Null until complete |
| error_message | text | Null unless error |
| created_at | datetime | |
| completed_at | datetime | Null until done |

## API Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/research` | Submit topic → returns `{ job_id }` |
| `GET` | `/research/{job_id}` | Poll status + report when done |
| `GET` | `/research/{job_id}/stream` | SSE stream of stage progress events |
| `GET` | `/research` | List all past jobs/reports |

### POST /research request body
```json
{ "topic": "Electric vehicle battery market in Southeast Asia" }
```

### GET /research/{job_id} response
```json
{
  "job_id": "abc123",
  "topic": "...",
  "status": "done",
  "current_stage": "write",
  "report_markdown": "# Market Research Report\n...",
  "created_at": "2026-04-15T10:00:00Z",
  "completed_at": "2026-04-15T10:02:30Z"
}
```

## Frontend (React)

**Layout (single page):**
- Header: "Market Research Agent"
- Research form: text input for topic + "Generate Report" button
- Progress tracker: 4 steps (Plan → Search → Synthesize → Write), each lights up as the pipeline advances (via SSE or polling)
- Report viewer: rendered markdown (using `react-markdown`) with a "Download .md" button
- Past reports list: below the form, shows previous jobs with topic, date, and "View" link

**State management:** React hooks (useState, useEffect) — no external state library needed for v1.

**Styling:** Tailwind CSS for clean, minimal UI.

## Error Handling

- If Tavily search fails for a query: skip that result, log warning, continue with remaining results
- If Claude call fails: retry once, then mark job as `error` with message
- If entire pipeline fails: job status = `error`, frontend shows error state with retry button
- Input validation: topic must be non-empty, max 500 chars
